# 火柴人格斗 · Stick Fighter

一个纯前端的火柴人格斗小游戏，单个 HTML 文件即可运行，物理引擎用 Matter.js。

## 运行方式

双击 `stick-fighter.html` 在浏览器打开即可（首次加载需联网，Matter.js 走 CDN）。

## 玩法

- 双人本地对战 / 单人打电脑
- 三张地图：擂台 / 平台 / 悬崖（掉坑扣血）

## 操作

| 动作 | 红方(玩家1) | 蓝方(玩家2) |
|---|---|---|
| 移动 | `A` `D` | `←` `→` |
| 跳跃 | `W` | `↑` |
| 格挡 | `S` | `↓` |
| 拳（连按三段连招） | `F` | `K` |
| 踢 | `G` | `L` |
| 气功波（消耗气） | `H` | `J` |

## 功能

- 三段连招拳、气功波、防御格挡
- AI 电脑对手（带攻击冷却 / 反应格挡 / 避坑跳）
- 血量条 + 气条、连击计数、命中顿帧、屏幕震动、粒子特效
- 音效（WebAudio 合成，无外部资源）

## 技术栈

- 原生 JavaScript + HTML5 Canvas
- [Matter.js](https://brm.io/matter-js/) 物理引擎
